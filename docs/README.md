# Docs

The root [README](../README.md) is the map: what this is, how to run it, and the short version of
every decision. These files are the long version, kept out of the README so first contact stays
short.

| File | What is in it |
| --- | --- |
| [architecture.md](architecture.md) | The agent loop, the money path, observability, the audit view, the evals view, and the human decision queue, with the files that own each |
| [decisions.md](decisions.md) | Every design decision with the alternative that was considered and why it was not taken |
| [assumptions.md](assumptions.md) | Every assumption made where the brief was ambiguous |
| [evaluation.md](evaluation.md) | The eval suite, the judge and its calibration, the run archive, per-run cost, prompt versioning, how to read the comparison, and the external review's 12 findings |
| [failure-modes.md](failure-modes.md) | What breaks or drifts, including the prompt-drift incidents that shaped the current system-prompt rules |
| [roadmap.md](roadmap.md) | Work deliberately left undone, with the reason it was scoped out |
| [plans/](plans/) | One numbered file per body of work, written before that work started and kept as a record of the reasoning |

Current pass/fail numbers are not here: they live in [`evals/RESULTS.md`](../evals/RESULTS.md),
regenerated by every `npm run eval` (runs the suite and rewrites the gate files).
